Функционал интернет магазина:

Реализовано:

1.Карточка товара и информация о товаре с возвратом на роут /
2.Витрина товаров роут /
3.Корзна с возможность оформить и оплатить в последствии товар, удалить товар, пересчет остатков на складе, и пересчет общей суммы
4.Администрор пользователей и товаров из интерфейса с возможностью удаление и изменени етоваров и пользователей.

Реализована ролевая модель (Админ/Неадмин) в дальнейшем она м ожет быть расширена.
К ролевой модели привязаны отображение форм html элементов.

Взаимодействие с БД реализовано через SQLAlchemy ORM 
Описана модель данных БД /models

Реализована очистка корзины после заказа товара, весь процесс с точки зрения браузщера организован с помощью session чтобы браузер запоминал.
В целом Инт.Магазин реализован на FLASK используя взаимодейцствие с html шаблонами /templates



В целом на сегодняшний день данных хватить для первичной аналитики товаров, оплат, пользователей,поставщиков, номеров заказов.
